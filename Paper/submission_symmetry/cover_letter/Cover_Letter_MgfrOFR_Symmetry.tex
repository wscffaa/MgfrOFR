\section*{Principal Revisions}

\begin{enumerate}
\item \textbf{Main configuration and symmetry justification (Reviewer 2, Comment 1; Reviewer 1, Comments 1 and 3).} The revised manuscript defines the main MgfrOFR configuration as MGFE+RATR with average restoration-token fusion and keeps max fusion as a fusion-ablation control. We strengthened the symmetry interpretation by introducing two formal invariance properties, branch permutation and forward/backward direction swap, and by narrowing the claim to functional and representation-level symmetry.

\item \textbf{Novelty positioning and difference analysis (Reviewer 1, Comment 1).} We added focused positioning prose that distinguishes MGFE/RATR from multi-scale pyramids, token-stripe recognition models, Mamba-based restoration, and generic diversity regularization, clarifying that the increment over MambaOFR is granularity decomposition plus ranking-aware diversity regularization.

\item \textbf{Fair comparison protocol (Reviewer 1, Comment 2).} We revised the comparison text to separate task-matched old film restoration baselines from enhancement-oriented reference methods and to state the evaluation protocol, adaptation policy, and metric interpretation more explicitly.

\item \textbf{Extended ablation and sensitivity study (Reviewer 1, Comment 3; Reviewer 2, Comment 3).} We expanded the ablation and sensitivity analysis to cover MGFE, RATR, average versus max fusion, ranking temperature, token insertion, and branch aggregation. The tables and discussion now explain the fidelity--perception trade-off and justify average fusion as the main configuration.

\item \textbf{Direct RATR validation (Reviewer 2, Comment 2).} We complemented quantitative results with direct evidence from pairwise branch-similarity analysis and pixel-domain absolute-error maps, showing how RATR reduces branch redundancy and broadens restoration gains.

\item \textbf{Qualitative figures and supplementary video (Reviewer 1, Comment 4; Reviewer 2, Comments 4 and 8).} We rebuilt the synthetic and real-world qualitative comparisons using full-method layouts and added Supplementary Video S1. The video contains a synthetic part with paired ground truth and per-frame PSNR, followed by a real-world SRWOV part annotated with no-reference NIQE and BRISQUE values.

\item \textbf{Efficiency analysis (Reviewer 1, Comment 5).} We quantified parameters, FLOPs, latency, FPS, and peak GPU memory under a unified L40 FP32 protocol and added a matched runtime comparison to isolate the cost of the proposed design over MambaOFR.

\item \textbf{Failure-case and limitations discussion (Reviewer 1, Comment 6).} We expanded the Discussion and Limitations sections to cover synthetic-to-real transfer, no-reference metric limits, training-time cost, the absence of an expert reader study, and the need for broader archival validation.

\item \textbf{Reproducibility (Reviewer 2, Comment 5).} We added implementation details on truncated-normal token initialization (standard deviation 0.02), the insertion operator, hyperparameter selection, data availability, and public code/configuration availability.

\item \textbf{English language and references (Reviewer 2, Comments 6, 9 and 10).} We shortened repetitive passages in the Introduction, unified terminology, checked the references and in-text citations, and proofread the revised manuscript.
\end{enumerate}
